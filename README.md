# Study Garden (Pomodoro Garden)

A Pomodoro timer where every completed focus session grows a plant in a garden in one of eight cities.

Final project by Nour El Ghobri, IE University, Madrid.

Open `index.html` in a browser, or visit the GitHub Pages link. Progress is saved in your own browser only.
